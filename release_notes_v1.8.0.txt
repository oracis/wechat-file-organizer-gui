v1.8.0 更新说明
================

新增「检查更新」能力，让普通用户也能轻松跟上新版本：

1) 启动后静默检查
   - 程序打开约 2 秒后，自动查询 GitHub 上本仓库的最新 Release 版本。
   - 若已是最新：不打扰。若有新版本：仅在底部状态栏提示「发现新版本 vX.Y.Z，点『检查更新』查看下载链接」。

2) 手动检查
   - 点顶部「检查更新」按钮，弹出新版本号、当前版本号与 exe 下载直链。
   - 方便用户一键复制链接去下载。

3) 隐私与健壮性
   - 纯本地用 Python 标准库 `urllib` 查询 GitHub 公开 Releases API，**不需要登录、不读任何凭据、不上传任何信息**。
   - 断网 / API 限流时静默失败，绝不弹报错打扰（手动检查时才会提示失败原因）。
   - 版本比较按语义化版本号（如 1.8.0 > 1.7.0），不会因 tag 格式误报。

安全提醒不变：扫描只读；归类只复制；清理原始文件一律走回收站（可恢复）。
