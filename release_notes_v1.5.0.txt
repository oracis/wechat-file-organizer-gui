微信文件自动归类 GUI v1.5.0 发布说明
=====================================

改进点
------
1. 文件列表拆分为两个标签页：
   - 「原始文件」：显示扫描到的微信源文件，新增「状态」列（待归类 / 已归类）。
   - 「归类副本」：一键归类后自动列出输出目录里的所有副本，并显示原始文件路径。
2. 删除后自动刷新：
   - 删除原始文件（回收站）后，「原始文件」列表自动移除已不存在的条目。
   - 删除归类副本后，「归类副本」列表自动移除已不存在的条目。
3. 一键归类完成后自动切换到「归类副本」标签页，方便立即查看整理结果。
4. 右键菜单根据当前标签页动态显示：
   - 「原始文件」页：打开 / 打开所在文件夹 / 删除此原始文件（回收站）。
   - 「归类副本」页：打开 / 打开所在文件夹 / 删除此归类副本。
5. 窗口默认尺寸略微放大，以容纳新增列和双标签页。

修复
----
- 修复了删除原始文件后文件列表仍显示已删除文件的问题。
- 修复了归类文件与原始文件在同一个列表中无法直观区分的问题。

安全提示
--------
- 「清理原始文件」仍然只删除已成功复制到输出目录的原始文件，并移入 Windows 回收站（可恢复）。
- 「删除归类副本」只影响输出目录，绝不碰微信源文件。
