# 微信文件自动归类（图形界面版）

给**只装了微信、没装任何编程工具**的普通人用的图形界面小工具。
双击打开，自动找到微信下载的文件，按类型 / 月份整理好，一键复制到干净的新目录。

> 这是 [`wechat-file-organizer`](https://github.com/oracis/wechat-file-organizer) 的**独立桌面版**。
> 那个仓库是给 AI 助手（WorkBuddy 等）调用的「技能」；本仓库是**人人能用的 exe 程序**。

---

## 下载与使用

1. 到 [Releases](../../releases) 下载 `WeChatFileOrganizer.exe`（单文件，免安装）。
2. 双击运行（Windows 10/11）。
3. 程序会**自动探测**微信文件目录并填好（兼容 `WeChat Files` / `Weixin Files` / `xwechat_files` 及自定义路径）；若没找到，点「浏览」手动选。
4. **输出目录默认就是桌面「微信文件整理」**，无需手动填。
5. 微信目录填好后，程序会**自动扫描**并把结果显示在下方；你也可以随时点「扫描」重新刷新。
6. 在「归类类别」里**勾选要整理的类别**（默认全选；不想搬大视频就取消勾选「视频」）。
7. 在「文件列表」里**双击任意文件即可预览/打开**；右键可「删除此文件的归类副本」。
8. 确认无误，点「一键归类」，勾选的类别会被复制到输出目录。
9. 整理完若想清理输出副本：点「清空归类文件夹」，或在文件列表右键逐个删除副本（**只删输出副本，绝不碰微信源文件**）。
10. 想要**顺手清理微信里的原始文件、腾出空间**：点「清理原始文件（回收站）」，或右键文件列表条目「删除此文件的原始文件（回收站）」。**清理原始文件前无需先归类；若已有归类副本则副本会完整保留，原始文件本身也会移入回收站（可在回收站恢复）**，避免误删。

**如果你的微信目录不是传统的 `WeChat Files\账号\FileStorage\File` 结构**（例如自定义存储路径、新版微信使用 `msg\file\YYYY-MM` 结构），程序会**自动启用「扫描整个文件夹」**：递归扫描整个目录，忽略微信系统文件（`.dat`/`.db`/`.mmkv` 等），只归类你真正接收过的文档/图片/视频/音频。也可手动勾选「扫描整个文件夹（适合新版微信）」复选框。

**核心安全底线**：扫描只读；归类只复制；删除原始文件前必须先有一份成功复制的副本，且一律移入回收站（可恢复），绝不永久删除微信源文件。

## 首次运行提示（重要）

本程序是开源免费工具，**没有购买商业代码签名证书**，因此 Windows 第一次运行下载来的 `WeChatFileOrganizer.exe` 时，可能会弹出「Windows 已保护你的电脑 / 无法验证发布者」之类的安全提示。

这**不是程序有问题**，按下面任一方式即可正常打开：

- **方式一（最常见）**：在提示窗口底部点「仍要运行 / 运行(R)」或「更多信息 → 仍要运行」，即可启动。
- **方式二（被系统拦截时）**：右键 `WeChatFileOrganizer.exe` → **属性** → 底部勾选 **解除锁定(Unblock)** → 确定，再双击运行。
- **方式三（彻底信任）**：若你担心，可改用本仓库源码自行打包（见下方「自己重新打包」），从自己电脑生成的 exe 不会触发该提示。

> 说明：Microsoft 从 2024 年起，即便购买 EV 代码签名证书也不再能「一键消除」SmartScreen 提示，需靠下载量积累信誉。作为小工具，我们选择了不花钱、靠上述方式运行的方案；若以后用户量大，再考虑申请开源免费签名或上架 Microsoft Store。

## 功能

- **自动探测**微信文件目录并填好源路径（兼容 `WeChat Files` / `Weixin Files` / `xwechat_files` 及自定义路径，有限深度扫描 `msg\file`、`FileStorage` 特征目录）。
- **默认输出到桌面「微信文件整理」**，普通用户无需理解路径概念，归类完直接在桌面找到。
- **扫描整个文件夹（适合新版微信）**：自动或手动开启，递归扫描任意微信目录，跳过微信内部系统与缓存文件。
- **归类后自动打开输出文件夹**：一键归类完成后会自动弹出输出文件夹窗口，不用再去桌面找。
- **记住上次设置**：关闭程序时自动保存整理方式、筛选条件、类别勾选和输出目录，下次打开不用重新选。
- **打开输出文件夹按钮**：随时点顶部「打开输出文件夹」即可查看已整理好的文件。
- **多种整理方式**（下拉框中文选项，选好立即显示整理示例）：
  - 按文件类型（文档 / 图片 / 压缩包 / 视频 / 音频 / 其他）
  - 按月份（2026-01、2026-02…）
  - 按年份（2026…）
  - 按类型+月份（推荐，最清晰）
  - 按类型+年份
  - 按年份+月份
  - 按类型+年份+月份
  
  不需要懂模板或令牌，选一个就能在界面上看到类似「文件会被整理到：文档/2026-03/文件名.pdf」的示例。
- **分类勾选**：「归类类别」区可分别勾选文档/图片/视频/音频/压缩包/其他，未勾选的类别在归类时被跳过；统计与文件列表实时显示「将归类」状态。
- **文件列表与预览**：底部文件列表分为**「原始文件」和「归类副本」两个标签页**，互不混淆；**双击即打开预览**（图片内联弹出，其他类型用系统默认程序打开），右键菜单可「打开 / 打开所在文件夹」。原始文件页显示扫描到的微信源文件（状态列提示「待归类/已归类」）；归类成功后归类副本页自动列出输出目录里的所有副本，并标注原始文件路径。
- **删除已归类副本**：在「归类副本」标签页右键条目可「删除此归类副本」，或点「清空归类文件夹」一键清空输出目录。**只删除输出目录的副本，微信源文件永不删除、不移动**；删除后列表自动刷新。
- **清理原始（源）文件**：在「原始文件」标签页右键「删除此原始文件（回收站）」，或点顶部「清理原始文件（回收站）」批量操作。清理原始文件**无需先归类**；若文件已有归类副本，输出目录副本会保留；若尚未归类，也会在确认后把原始文件**移入回收站（可在回收站恢复）**，绝不永久删除。删除后「原始文件」列表会自动刷新，已移入回收站的项不再显示。批量清理时会提示「已有副本数 / 尚未归类数」，方便你确认。
- **按时间筛选（扫描时生效）**：在「扫描筛选」区选择时间范围——全部 / 最近7天 / 最近30天 / 最近90天 / 今年 / 自定义。选「自定义」后可填起止日期（格式 `YYYY-MM-DD`），只归类该时间段修改过的文件；被过滤掉的文件会在日志里提示数量。
- **按大小筛选（扫描时生效）**：在「扫描筛选」区选择文件大小下限——全部 / ≥1MB / ≥10MB / ≥100MB / 自定义(MB)。选「自定义(MB)」后可填最小大小（单位 MB，支持小数如 `0.5`），只归类不小于该大小的文件；被过滤掉的文件同样会在日志里提示数量。
- **顶部使用提示横幅**：打开程序就能看到「三步完成整理」的直白说明，不用猜每个按钮什么意思。
- **启动自动扫描**：只要微信目录已填好，打开程序 1 秒后会自动扫描并显示结果，不用先点「扫描」。
- **整理方式实时示例**：在「归类设置」里选好整理方式后，界面会立即显示一个示例路径（如 `文档/2026-03/文件名.pdf`），普通人也能一眼看懂文件会被放到哪里。
- **检查更新**：程序启动后会**静默查询** GitHub 上的最新 Release 版本，发现新版本只在状态栏提示；点「检查更新」按钮可弹出新版本号与下载链接。纯本地 `urllib` 查询、无需登录、不收集任何信息、断网时静默跳过。
- **去重**：相同内容的文件只保留一份，重复项跳过并报告可节省空间。
- **预览优先**：扫描只出报告，任何改动都要你点「一键归类」才发生。
- **中文友好**：目录、文件名、统计全中文无乱码。
- **零依赖**：纯 Python 标准库，打包后单 exe 即可运行。

## 安全说明

- 默认**只读扫描**，绝不触碰你的文件。
- 「一键归类」只做 `复制`，**不删除、不移动**源文件，随时可删输出目录重来。
- 「清理原始文件」是**可选、显式确认**的操作：删除前会弹出提示，列出数量、总大小，以及其中已有归类副本和尚未归类的数量。所有原始文件都会通过 Windows 回收站（可恢复）而非永久删除。若文件已有归类副本，副本会完整保留。
- 不联网、不上传、不读任何凭据。纯本地工具。

## 自己重新打包（开发者）

需要 Windows + 含 Tcl/Tk 的 Python 3.10+（官方安装包默认包含）。

```bat
build.bat
```

或手动：

```bat
python -m venv build\venv
build\venv\Scripts\python.exe -m pip install pyinstaller
build\venv\Scripts\pyinstaller --onefile --windowed --name WeChatFileOrganizer main.py
```

产物在 `dist\WeChatFileOrganizer.exe`。

> 注意：WorkBuddy 自带的精简 Python 没有 tkinter，打包请用自己的系统 Python。
