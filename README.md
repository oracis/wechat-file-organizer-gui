# 微信文件自动归类（图形界面版）

给**只装了微信、没装任何编程工具**的普通人用的图形界面小工具。
双击打开，自动找到微信下载的文件，按类型 / 月份整理好，一键复制到干净的新目录。

> 这是 [`wechat-file-organizer`](https://github.com/oracis/wechat-file-organizer) 的**独立桌面版**。
> 那个仓库是给 AI 助手（WorkBuddy 等）调用的「技能」；本仓库是**人人能用的 exe 程序**。

---

## 下载与使用

1. 到 [Releases](../../releases) 下载对应平台的安装包：
   - **Windows**：`WeChatFileOrganizer.exe`（单文件，免安装）；
   - **macOS（Apple Silicon）**：`WeChatFileOrganizer-macOS-arm64.pkg`（安装到「应用程序」）或 `WeChatFileOrganizer-macOS-arm64.zip`（解压即用）。
2. 双击运行（Windows 10/11 / macOS 12+）。
3. 程序会**自动探测**微信文件目录并填到「① 选择微信文件所在的文件夹」（兼容 `WeChat Files` / `Weixin Files` / `xwechat_files` 及自定义路径）；若没找到，该处会**红色提示**你点「换个文件夹」手动选。
4. **输出目录默认就是桌面「微信文件整理」**，无需手动填。
5. 微信目录填好后，程序会**自动扫描**并在「③ 预览并整理」处显示「将整理 N 个文件，共 X」（也可随时点「重新扫描」刷新）。
6. 在「② 选择要整理的文件类型」里**勾选要整理的类型**（默认全选；不想搬大视频就取消勾选「视频」）。想用进阶功能——改整理方式 / 去重 / 按时间或大小筛选 / 扫描整个文件夹——点「高级选项」展开即可，平时不用管。
7. 点「③ 预览并整理」里的大按钮 **「开始整理」**（默认只复制、不动微信原文件；想顺手腾空间可勾选下方「整理后顺便清理微信原文件（移入回收站，可恢复）」）。想先看文件清单，点「查看文件清单」展开；**单击图片可在下方看缩略图，双击任意文件即可预览/打开**，右键可删除。
8. 整理完若想清理输出副本：点「清空整理结果」，或在「归类副本」页右键逐个删除副本（**只删输出副本，绝不碰微信源文件**）。
9. 想要**顺手清理微信里的原始文件、腾出空间**：点「清理微信原文件（回收站）」，或右键文件列表条目「删除此原始文件（回收站）」。**清理原始文件前无需先归类；若已有归类副本则副本会完整保留，原始文件本身也会移入回收站（可在回收站恢复）**，避免误删。

**如果你的微信目录不是传统的 `WeChat Files\账号\FileStorage\File` 结构**（例如自定义存储路径、新版微信使用 `msg\file\YYYY-MM` 结构），程序会**自动启用「扫描整个文件夹」**：递归扫描整个目录，忽略微信系统文件（`.dat`/`.db`/`.mmkv` 等），只归类你真正接收过的文档/图片/视频/音频。也可手动勾选「扫描整个文件夹（适合新版微信）」复选框。

**核心安全底线**：扫描只读；归类只复制；删除原始文件前必须先有一份成功复制的副本，且一律移入回收站（可恢复），绝不永久删除微信源文件。

## 首次运行提示（重要）

本程序是开源免费工具，**没有购买商业代码签名证书**，因此 Windows 第一次运行下载来的 `WeChatFileOrganizer.exe` 时，可能会弹出「Windows 已保护你的电脑 / 无法验证发布者」之类的安全提示。

这**不是程序有问题**，按下面任一方式即可正常打开：

- **方式一（最常见）**：在提示窗口底部点「仍要运行 / 运行(R)」或「更多信息 → 仍要运行」，即可启动。
- **方式二（被系统拦截时）**：右键 `WeChatFileOrganizer.exe` → **属性** → 底部勾选 **解除锁定(Unblock)** → 确定，再双击运行。
- **方式三（彻底信任）**：若你担心，可改用本仓库源码自行打包（见下方「自己重新打包」），从自己电脑生成的 exe 不会触发该提示。

> 说明：Microsoft 从 2024 年起，即便购买 EV 代码签名证书也不再能「一键消除」SmartScreen 提示，需靠下载量积累信誉。**好消息**：本项目已把 [SignPath Foundation](https://signpath.org/) 的**免费开源代码签名**接入 CI（见 `docs/windows-code-signing.md`）。只要按文档申请到免费证书、在仓库填入 4 个密钥/变量，之后每次发版（打 tag 推上去）产出的 exe 都会**自动带上 Authenticode 签名**，SmartScreen 弹窗随之消失。在配置完成前，下面的方式一/二/三仍可正常打开未签名版本。

### macOS 首次运行提示

macOS 包（pkg/zip）**未做 Apple 签名与公证**（开发者证书 $99/年，暂未购买），首次打开会被 Gatekeeper 拦截，这**不是程序有问题**，任选其一：

- **方式一**：把 app 放进「应用程序」后，**右键 → 打开 → 再点「打开」**（只需一次）。
- **方式二（彻底）**：终端执行 `xattr -cr /Applications/WeChatFileOrganizer.app` 后正常双击打开。

> macOS 版会自动探测新版 Mac 微信的沙盒目录（`~/Library/Containers/com.tencent.xinWeChat/...`），按 `MessageTemp/<会话>` 结构收集接收文件；清理原文件走「Finder 移入废纸篓」（可恢复）。当前包为 **Apple Silicon（arm64）** 版，Intel Mac 暂不支持。

## 功能

- **自动探测**微信文件目录并填好源路径（兼容 `WeChat Files` / `Weixin Files` / `xwechat_files` 及自定义路径，有限深度扫描 `msg\file`、`FileStorage` 特征目录）。
- **多微信账号合并扫描**：自动探测电脑上**所有**微信文件根目录（新版 `xwechat_files` 与旧版 `WeChat Files` 可同时存在），一次性合并扫描所有账号的文件，并在顶部显示「已合并扫描 N 个微信账号：a、b」；文件清单会自动多出一列「微信账号」，标明每个文件属于哪个账号（只有一个账号时该列自动隐藏，不占空间）。可在「高级选项」里取消勾选「合并扫描其他微信账号」。
- **图片内嵌缩略图预览**：展开「查看文件清单」后，下方有图片预览面板——**单击选中**任意图片文件，立刻显示缩略图、原始尺寸、大小和修改时间（支持 jpg / png / gif / bmp / webp，选中即看、带缓存不卡顿）；**双击**弹出适配屏幕的大图窗口，并可一键「用系统程序打开」或「打开所在文件夹」。非图片文件会给出友好提示而非报错。
- **默认输出到桌面「微信文件整理」**，普通用户无需理解路径概念，归类完直接在桌面找到。
- **扫描整个文件夹（适合新版微信）**：自动或手动开启，递归扫描任意微信目录，跳过微信内部系统与缓存文件。
- **归类后自动打开输出文件夹**：一键归类完成后会自动弹出输出文件夹窗口，不用再去桌面找。
- **自动生成整理清单.csv**：一键归类后会在输出目录生成 `整理清单.csv`（文件名 / 类别 / 大小 / 原始路径 / 整理后路径），方便核对每个文件的去向，用 Excel 直接打开。
- **记住上次设置**：关闭程序时自动保存整理方式、筛选条件、类别勾选和输出目录，下次打开不用重新选。
- **打开整理好的文件夹按钮**：随时点「打开整理好的文件夹」即可查看已整理好的文件。
- **多种整理方式**（下拉框中文选项，选好立即显示整理示例）：
  - 按文件类型（文档 / 图片 / 压缩包 / 视频 / 音频 / 其他）
  - 按月份（2026-01、2026-02…）
  - 按年份（2026…）
  - 按类型+月份（推荐，最清晰）
  - 按类型+年份
  - 按年份+月份
  - 按类型+年份+月份
  
  不需要懂模板或令牌，选一个就能在界面上看到类似「文件会被整理到：文档/2026-03/文件名.pdf」的示例。
- **分类勾选**：「② 选择要整理的文件类型」区可分别勾选文档/图片/视频/音频/压缩包/其他，未勾选的类别在归类时被跳过；预览文字与文件列表实时显示「将归类」状态。
- **文件列表与预览**：点「查看文件清单」展开后，列表分为**「原始文件」和「归类副本」两个标签页**，互不混淆；**单击图片即在下方内嵌面板显示缩略图，双击即打开大图预览**（非图片类型用系统默认程序打开），右键菜单可「打开 / 打开所在文件夹」。原始文件页显示扫描到的微信源文件（状态列提示「待归类/已归类」）；归类成功后归类副本页自动列出输出目录里的所有副本，并标注原始文件路径。
- **删除已归类副本**：在「归类副本」标签页右键条目可「删除此归类副本」，或点「清空整理结果」一键清空输出目录。**只删除输出目录的副本，微信源文件永不删除、不移动**；删除后列表自动刷新。
- **清理原始（源）文件**：在「原始文件」标签页右键「删除此原始文件（回收站）」，或点「清理微信原文件（回收站）」批量操作。清理原始文件**无需先归类**；若文件已有归类副本，输出目录副本会保留；若尚未归类，也会在确认后把原始文件**移入回收站（可在回收站恢复）**，绝不永久删除。删除后「原始文件」列表会自动刷新，已移入回收站的项不再显示。批量清理时会提示「已有副本数 / 尚未归类数」，方便你确认。
- **按时间筛选（扫描时生效）**：在「高级选项」里选择时间范围——全部 / 最近7天 / 最近30天 / 最近90天 / 今年 / 自定义。选「自定义」后可填起止日期（格式 `YYYY-MM-DD`），只归类该时间段修改过的文件；被过滤掉的文件会在日志里提示数量。
- **按大小筛选（扫描时生效）**：在「高级选项」里选择文件大小下限——全部 / ≥1MB / ≥10MB / ≥100MB / 自定义(MB)。选「自定义(MB)」后可填最小大小（单位 MB，支持小数如 `0.5`），只归类不小于该大小的文件；被过滤掉的文件同样会在日志里提示数量。
- **三步向导式布局**：整个界面按「① 选微信文件夹 → ② 选类型 → ③ 预览并整理」的顺序排布，大号主按钮「开始整理」一目了然；进阶功能（整理方式 / 去重 / 扫描范围 / 时间 / 大小筛选 / 文件清单 / 日志）默认收进可折叠区，小白打开即用、老手展开也有全部能力。
- **启动自动扫描**：只要微信目录已填好，打开程序约 1 秒后会自动扫描并显示结果，不用先点「扫描」。
- **整理方式实时示例**：在「高级选项」里选好整理方式后，界面会立即显示一个示例路径（如 `文档/2026-03/文件名.pdf`），普通人也能一眼看懂文件会被放到哪里。
- **检查更新**：程序启动后会**静默查询** GitHub 上的最新 Release 版本，发现新版本只在状态栏提示；点「检查更新」按钮可弹出新版本号与下载链接。纯本地 `urllib` 查询、无需登录、不收集任何信息、断网时静默跳过。
- **去重**：相同内容的文件只保留一份，重复项跳过并报告可节省空间。
- **预览优先**：扫描只出报告，任何改动都要你点「一键归类」才发生。
- **中文友好**：目录、文件名、统计全中文无乱码。
- **零依赖**：只用 Python 标准库即可运行（图片缩略图预览需要 Pillow，**装不上也不影响主功能**，程序会自动降级为双击用系统程序打开）。打包后单 exe 即可运行。

## 和微信自带的「文件管理」有什么区别

微信桌面端自带的「文件管理」适合**临时查看、找一两个文件**；本工具适合**定期批量归档、腾空间、做长期备份**。两者互补，不是替代。

| 能力 | 微信自带文件管理 | 本工具 |
|---|---|---|
| 按时间 / 类型 / 发送人查看 | ✅ | 按类型 / 时间 / 大小筛选 |
| 直接打开 / 预览文件 | ✅ 内嵌预览 | ✅ 单击看缩略图 / 双击看大图 / 调用系统程序 |
| **多微信账号一次性合并扫描** | ❌（只显示当前登录账号） | ✅ 自动探测并合并所有账号 |
| 单个文件另存为 | ✅ | ✅ 批量归类到本地 |
| **一键批量归档到本地目录** | ❌ | ✅ |
| **自动生成归档目录结构（类型/月份/年份）** | ❌ | ✅ |
| **一键去重（同名同内容只留一份）** | ❌ | ✅ |
| **生成「整理清单.csv」可核对去向** | ❌ | ✅ |
| **先复制归档、再安全清理原文件腾空间** | ❌ | ✅ |
| **显示文件来源（哪个群 / 谁发的）** | ✅ | ❌（微信加密存储，第三方读不到） |

**一句话总结**：微信文件管理只能「看和单个存」；本工具能「批量归档 + 多账号合并 + 去重 + 生成清单 + 安全腾空间」。

> 说明：微信把「文件来源」「发送人」这类信息存在加密数据库里，第三方工具无法读取，所以本工具无法按发送人/群筛选——这是微信文件管理独有的能力。若你需要按来源找文件，用微信自带；若你想把文件批量搬到本地、腾磁盘、做备份，用本工具。

## 安全说明

- 默认**只读扫描**，绝不触碰你的文件。
- 「一键归类」只做 `复制`，**不删除、不移动**源文件，随时可删输出目录重来。
- 「清理原始文件」是**可选、显式确认**的操作：删除前会弹出提示，列出数量、总大小，以及其中已有归类副本和尚未归类的数量。所有原始文件都会通过 Windows 回收站（可恢复）而非永久删除。若文件已有归类副本，副本会完整保留。
- 不联网、不上传、不读任何凭据。纯本地工具。

## 自己重新打包（开发者）

需要 Windows + 含 Tcl/Tk 的 Python 3.10+（官方安装包默认包含）。

```bat
build.bat
```

或手动：

```bat
python -m venv build\venv
build\venv\Scripts\python.exe -m pip install pyinstaller pillow
build\venv\Scripts\pyinstaller --onefile --windowed --name WeChatFileOrganizer --exclude-module numpy main.py
```

> `--exclude-module numpy` 用于去掉 Pillow 间接带入的 numpy（本工具不用，可省约 12MB）。

产物在 `dist\WeChatFileOrganizer.exe`。

> 注意：WorkBuddy 自带的精简 Python 没有 tkinter，打包请用自己的系统 Python。

**macOS 本地打包**（需真 Mac，PyInstaller 无法在 Windows 上交叉编译）：

```bash
python3 -m pip install pyinstaller pillow
pyinstaller --windowed --name WeChatFileOrganizer --exclude-module numpy main.py
# 产物 dist/WeChatFileOrganizer.app；如需安装包：
pkgbuild --root dist --identifier com.oracis.wechat-file-organizer \
  --version 1.16.0 --install-location /Applications WeChatFileOrganizer-macOS-arm64.pkg
```

### 自动构建与发布（推荐）

本项目已配置 GitHub Actions（`.github/workflows/build-and-sign.yml`）：**Windows job** 在 GitHub 托管的 Windows 上用 PyInstaller 构建单文件 exe，可选地经 SignPath 签名后自动建 Release 并上传；**macOS job** 在 GitHub 托管的 macOS（Apple Silicon）上构建 `.app`，并用 `pkgbuild`/`ditto` 产出**未签名的 .pkg 安装包与 .zip**，自动上传到同一个 Release。

发布新版本只需打 tag 推上去：

```bash
git tag v1.16.0
git push origin v1.16.0
```

也可在 Actions 标签手动 `Run workflow` 并填写版本号。若仓库里还没配置 SignPath 的四个密钥/变量，工作流会自动跳过签名、照常发布**未签名**的 exe，不会中断发布流程（详见 `docs/windows-code-signing.md`）。
